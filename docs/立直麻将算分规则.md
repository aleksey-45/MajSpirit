## 1. 总流程

算分不是一步到位的，必须按固定顺序走，顺序错了结果就错：

```
① 拆解和牌型        →  4 面子 + 1 雀头，或 七对子，或 国士无双
② 判定役种          →  有哪些役、各几翻
③ 无役？            →  直接不能和牌（这是最常见的「诈和」）
④ 有役满？          →  是则跳过 ⑤⑥，直接按役满倍数结算
⑤ 计算符数          →  副底 + 面子 + 雀头 + 待ち + 自摸 + 门清荣和
⑥ 汇总翻数          →  役翻数 + 宝牌 + 里宝 + 赤宝
⑦ 查基本点          →  符 × 2^(2+翻)，超过上限则封顶
⑧ 切上到百位        →  按支付规则换算成各家实际收支
⑨ 加本场与供托      →  本场棒、立直棒
```

**为什么顺序重要**：符数在役满时完全不参与计算；宝牌不算役（不能靠宝牌和牌），
但在非役满时计入翻数。这两点搞反就会算错。

## 2. 和牌的前提：必须有役

**没有役就不能和牌**，哪怕牌型是合法的「4 面子 + 1 雀头」。这是立直麻将和很多地方麻将
最本质的区别，也是最容易在实现时漏掉的一条。

判定顺序建议：

1. 先做**牌型拆解**，能拆出合法和牌型才继续（拆不出来直接不和）
2. 再**枚举役种**，累计翻数
3. **翻数为 0 且没有役满 → 不能和牌**

注意「宝牌」不是役。手里攥着 4 张宝牌但一个役都没有，照样不能和。

## 4. 宝牌

| 种类 | 翻数 | 出现条件 |
|---|:--:|---|
| 宝牌（表）| +1 / 张 | 翻开宝牌指示牌的下一张 |
| 里宝牌 | +1 / 张 | **立直和牌**时额外翻开 |
| 赤宝牌 | +1 / 张 | 红 5 万、红 5 条、红 5 饼，每种一张 |

**宝牌指示牌 → 宝牌**的对应关系（循环）：

- 数牌：指示牌 1→2、2→3 … 9→1（同花色内循环）
- 风牌：东→南→西→北→东
- 三元牌：白→发→中→白

**三条铁律**：

1. **宝牌不算役**。没有役时宝牌再多也不能和。
2. **役满时不计宝牌**。已经役满就不再累加宝牌翻数。
3. 宝牌翻数参与封顶判定。例如 3 翻 + 5 张宝牌 = 8 翻 → 倍满。

## 5. 符数计算

符数由下面几项相加，最后**向上取整到 10 符**。

### 5.1 副底

任何和牌都有的基础符：**20 符**。

### 5.2 加符项

| 项目 | 符数 | 说明 |
|---|:--:|---|
| 门清荣和 | +10 | 门清状态下荣和 |
| 自摸 | +2 | **平和自摸除外**（见 5.4）|
| 雀头·役牌 | +2 | 三元牌、场风、自风 |
| 雀头·连风牌 | +4 | 场风与自风相同 |
| 待ち·单骑 | +2 | 听雀头 |
| 待ち·嵌张 | +2 | 听中间那张 |
| 待ち·边张 | +2 | 12 听 3 或 89 听 7 |
| 待ち·两面 | 0 | |
| 待ち·双碰 | 0 | 荣和时；自摸时该组按暗刻计符 |
| 顺子 | 0 | 任何顺子都是 0 符 |

### 5.3 面子符

| 面子 | 中张（2-8）| 幺九（1、9、字牌）|
|---|:--:|:--:|
| 明刻 | 2 | 4 |
| 暗刻 | 4 | 8 |
| 明杠 | 8 | 16 |
| 暗杠 | 16 | 32 |

**区分明暗**：由别人打出的牌组成的刻子/杠为明，自己摸到的为暗。
荣和的那张牌所组成的刻子**算明刻**（因为那张牌来自别人）。

### 5.4 两个特例

| 情况 | 符数 |
|---|---|
| **七对子** | 固定 **25 符**，不参与取整 |
| **平和自摸** | 固定 **20 符**（不加自摸的 2 符）|

### 5.5 常见符数速记

| 情况 | 符数 |
|---|:--:|
| 门清荣和·平和 | 30 |
| 门清自摸·非平和 | 30（20+2 取整）|
| 平和自摸 | 20 |
| 副露荣和·最低 | 30（20 取整）|
| 七对子 | 25 |
| 门清荣和·有暗刻 | 40 或更高 |

## 6. 翻数汇总

```
总翻数 = Σ(役种翻数) + 宝牌张数 + 里宝牌张数 + 赤宝牌张数
```

**门清与副露的翻数可能不同**（见第 3 节表格的门清/副露两列），
副露时按副露那一列取值。门清限定的役在副露后**完全不成立**。

**役满优先**：只要成立了役满，就不再看翻数，直接按役满倍数结算。

**累计役满**：翻数达到 13 翻以上（由普通役 + 宝牌累积而成）也算役满。

## 7. 基本点与满贯上限

### 7.1 基本点公式

```
基本点 = 符 × 2^(2 + 翻数)
```

例：30 符 4 翻 → `30 × 2^6 = 30 × 64 = 1920`

### 7.2 封顶

**基本点超过 2000 时，一律按满贯（2000）计算**，不再看符。

| 等级 | 条件 | 基本点 |
|---|---|:--:|
| 满贯 | 基本点 > 2000，或 5 翻 | 2000 |
| 跳满 | 6–7 翻 | 3000 |
| 倍满 | 8–10 翻 | 4000 |
| 三倍满 | 11–12 翻 | 6000 |
| 役满 | 13 翻以上，或役满役种 | 8000 |
| N 倍役满 | N 个役满复合 | 8000 × N |

### 7.3 切上满贯（可选规则）

按 7.1 的公式，**4 翻 30 符**的基本点是 `30 × 64 = 1920`，**没有超过 2000**，
严格按规则应算 7700（子家荣和）。

但多数现代规则集（包括天凤、雀魂）采用**切上满贯**：把 1920 这类临界值直接抬到满贯。

受影响的组合：

| 符×翻 | 严格基本点 | 严格点数（子荣和）| 切上后 |
|---|:--:|:--:|:--:|
| 30 符 4 翻 | 1920 | 7700 | 8000 |
| 60 符 3 翻 | 1920 | 7700 | 8000 |

**本项目采用切上满贯**。这是可以在配置里关掉的开关，见[第 14 节](#14-需要拍板的规则变体)。

## 8. 支付规则

设**基本点**为 B（已按第 7 节封顶）。各家实际支付额先算出来，再**向上取整到百位**。

| 和牌者 | 和牌方式 | 支付 |
|---|---|---|
| 子家 | 荣和 | 放铳者支付 `B × 4` |
| 子家 | 自摸 | 每个子家支付 `B × 1`，庄家支付 `B × 2` |
| 庄家 | 荣和 | 放铳者支付 `B × 6` |
| 庄家 | 自摸 | 三家各支付 `B × 2` |

**注意取整的时机**：是**每笔支付分别向上取整**，不是先求和再取整。

验证：子家 30 符 4 翻 自摸，B = 1920。

```
每个子家：1920 × 1 = 1920  → 取整 2000
庄家：    1920 × 2 = 3840  → 取整 3900
实际收支：2000 / 2000 / 3900      ← 标准值，正确
```

如果先求和再取整会得到 `1920×4 = 7680 → 7700`，与标准值 7900 不符。

**荣和有一家不付**：放铳者付全额，其余两家不付。所以子家荣和的总额是 `B × 4`
而不是 `B × 1 + B × 1 + B × 2`。

## 10. 本场、连庄与供托

### 10.1 本场棒

每积累一本场，和牌时**额外支付 300 点**（无论谁和牌）：

| 和牌方式 | 本场加成 |
|---|---|
| 荣和 | 放铳者额外支付 `300 × 本场数` |
| 自摸 | 三家**各**额外支付 `100 × 本场数` |

### 10.2 立直棒（供托）

宣告立直时支付 **1000 点**作为立直棒，累积在场上。
和牌者**全部收走**；流局时留在场上，累积到下一局。

### 10.3 连庄

| 情况 | 结果 |
|---|---|
| 庄家和牌 | 连庄，本场 +1 |
| 庄家听牌流局 | 连庄，本场 +1 |
| 其他 | 轮庄，本场清零 |

## 11. 流局

### 11.1 荒牌流局（牌山摸完）

进入**听牌料**结算：

- 未听牌者合计支付 **3000 点**，由听牌者均分

具体数额：

| 听牌人数 | 未听牌者每人支付 | 听牌者每人收到 |
|:--:|:--:|:--:|
| 1 人 | 1000 | 3000 |
| 2 人 | 1500 | 1500 |
| 3 人 | 3000 | 1000 |
| 0 或 4 人 | 0 | 0 |

算法：`未听牌者每人支付 = 3000 / 未听牌人数`，`听牌者每人收到 = 3000 / 听牌人数`。
两者互为倒数关系，都能整除，不会出现小数。

### 11.2 途中流局

| 名称 | 条件 |
|---|---|
| 九种九牌 | 第一巡，手上有九种以上幺九牌，可宣告 |
| 四风连打 | 第一巡四家打出同一张风牌 |
| 四家立直 | 四家全部立直 |
| 四杠散了 | 四家共开四杠（有变体，见第 14 节）|
| 三家和了 | 一炮三响（有变体）|

途中流局通常**不结算听牌料**，本场 +1，庄家连庄与否按各规则集约定。

## 12. 完整算例

### 例 1：门清荣和·平和

```
手牌（13 张）：234m 567m 234s 56s 88p
荣和 4s  →  234m 567m 234s 456s 88p
```

- **役**：平和（1 翻）、断幺九（1 翻）→ 2 翻
- **符**：副底 20 + 门清荣和 10 = 30 符
  （全顺子、雀头 88p 非役牌、56s 是两面听 → 无待ち符，也无刻子符）
- **基本点**：`30 × 2^4 = 480`
- **子家荣和**：`480 × 4 = 1920 → 2000`
- 结果：**2000 点**（与速查表 30 符 2 翻一致）

### 例 2：子家自摸·平和

- **役**：平和（1 翻）、门前清自摸和（1 翻）→ 2 翻
- **符**：**平和自摸固定 20 符**
- **基本点**：`20 × 2^4 = 320`
- **子家自摸**：子家 `320 → 400`，庄家 `640 → 700`
- 结果：**400 / 700**（标准值，正确）

### 例 3：七对子

- **役**：七对子（2 翻）→ 2 翻
- **符**：**25 符固定**
- **基本点**：`25 × 2^4 = 400`
- **子家荣和**：`400 × 4 = 1600`
- 结果：**1600 点**

### 例 4：副露·对对和

```
手牌（副露 2 组）：111m(碰) 999m(碰) 222s 333s 55z   荣和 3s
```

- **役**：对对和（2 翻）→ 2 翻
- **符**：
  - 副底 20
  - 111m 明刻·幺九 +4
  - 999m 明刻·幺九 +4
  - 222s 暗刻·中张 +4
  - 333s 荣和的牌组成的刻子算**明刻**·中张 +2
  - 55z 雀头·白（役牌）+2
  - 单骑待ち？不是，是双碰荣和 → +0
  - 副露所以无门清荣和 +10
  - 合计 36 → 取整 **40 符**
- **基本点**：`40 × 2^4 = 640`
- **子家荣和**：`640 × 4 = 2560 → 2600`
- 结果：**2600 点**

### 例 5：切上满贯的边界

```
门清荣和，立直 + 一发 + 门前清自摸和……不是自摸，是荣和
假设：立直(1) + 一发(1) + 断幺九(1) + 平和(1) = 4 翻，30 符
```

- **基本点**：`30 × 2^6 = 1920`，**未超过 2000**
- 严格按公式：子家荣和 `1920 × 4 = 7680 → 7700`
- **采用切上满贯**后：**8000**
- 本例正是切上满贯规则唯一会产生差异的常见场景，测试里必须覆盖

### 例 6：役满

```
国士无双（1 倍役满）
```

- 跳过符与翻数计算
- **子家荣和**：`8000 × 4 = 32000`
- **庄家荣和**：`8000 × 6 = 48000`
- **子家自摸**：`8000 / 16000`
- **庄家自摸**：`16000 all`

## 13. 实现建议

### 13.1 计算入口

```go
// Score 计算一次和牌的最终收支。
type ScoreInput struct {
    Hand        []Tile     // 和牌时的手牌（含和牌张）
    WinningTile Tile       // 和牌的那张
    IsTsumo     bool
    IsDealer    bool
    Melds       []Meld     // 副露（含暗杠）
    RoundWind   Tile       // 场风
    SeatWind    Tile       // 自风
    DoraIndicators []Tile  // 宝牌指示牌
    UraIndicators  []Tile  // 里宝牌指示牌（未立直则为空）
    IsRiichi    bool
    // ... 一发、岭上、海底等标志位
}

type ScoreResult struct {
    Yaku     []YakuHit   // 命中的役及翻数
    Han      int         // 总翻数
    Fu       int         // 符数
    Yakuman  int         // 役满倍数，0 表示非役满
    Payments [4]int      // 四个座位各自的收支，已含本场与供托
    Total    int         // 和牌者总收入（含供托）
}
```

### 13.2 建议拆成三个独立可测的部分

| 部分 | 输入 → 输出 | 特点 |
|---|---|---|
| **役种判定** | 拆解后的牌型 + 上下文 → `[]YakuHit` | 纯函数，最容易写错，测试最密 |
| **符数计算** | 牌型 + 和牌方式 → `int` | 纯函数，规则琐碎 |
| **点数换算** | 符 + 翻 + 庄闲 + 自摸/荣和 → 各座收支 | 纯函数，用速查表做表驱动测试 |

**不要让它们互相依赖**。役种判定不应该知道符数，符数计算不应该知道点数怎么分。
这样每一块都能独立测试，出错时能快速定位是哪一层的锅。

### 13.3 测试策略

**最重要的一点：用第 9 节的速查表做表驱动测试。**
点数是行业标准值，不存在"我们自己的约定"，所以可以直接硬编码期望值。

建议的测试层次：

1. **役种判定**：构造牌型，断言命中的役种与翻数。每个役种至少一个正例和一个反例。
2. **符数计算**：构造牌型，断言符数。重点覆盖明暗刻的区分、荣和那张牌算明刻、
   平和自摸 20 符、七对子 25 符、取整边界（如 36 符 → 40 符）。
3. **点数换算**：直接喂 `(符, 翻, 庄闲, 自摸/荣和)`，断言点数。把第 9 节的表全部搬进来。
4. **端到端**：第 12 节的六个算例，从手牌一路算到收支。

### 13.4 容易写错的地方

| 问题 | 说明 |
|---|---|
| 荣和的那张牌算明刻 | 即使自己手里本来就有两张，荣和第三张组成的刻子仍算明刻 |
| 副露后门清限定役全失效 | 不是降翻，是**完全不成立** |
| 副露后翻数取另一列 | 三色同顺等役门清 2 翻、副露 1 翻 |
| 平和自摸不加 2 符 | 否则算出来是 22 → 30 符，与标准的 20 符冲突 |
| 取整时机 | 每笔支付分别取整，不是先求和再取整 |
| 双碰荣和的待ち符 | 荣和时双碰待ち是 0 符；自摸时该组按暗刻计符 |
| 宝牌不算役 | 没有役时不能和牌，宝牌再多也不行 |
| 役满不计宝牌 | 役满时宝牌翻数不参与 |
| 连风牌是 2 翻 + 4 符 | 场风与自风相同时，两个役牌役都成立，雀头符也翻倍 |
| 切上满贯 | 30 符 4 翻、60 符 3 翻这两个临界值 |
| 立直棒归属 | 和牌者全收；流局留场 |

## 14. 需要拍板的规则变体

立直麻将有大量"各地规则不同"的地方。**必须在实现前明确选定**，
否则测试期望值会对不上。以下给出本项目的选择建议：

| 变体 | 选项 | 本项目选择 | 影响 |
|---|---|---|---|
| 切上满贯 | 采用 / 不采用 | **采用** | 30 符 4 翻 = 8000（而非 7700）|
| 四杠散了 | 流局 / 继续 | 流局 | 影响杠的处理 |
| 三家和了 | 流局 / 全家和牌 | 流局 | 影响一炮多响 |
| 累计役满 | 承认 / 不承认 | **承认** | 13 翻以上算役满 |
| 役满复合 | 可叠加 / 封顶单倍 | **可叠加** | 大四喜 + 字一色 = 3 倍 |
| 平和自摸 | 20 符 / 算作 20 符且不加自摸符 | **20 符** | 影响最常见的一手 |
| 连风牌雀头 | 4 符 / 2 符 | **4 符** | 影响东场东家的点数 |
| 赤宝牌 | 有 / 无 | **有**（各 1 张）| 增加宝牌翻数 |
| 流局满贯 | 采用 / 不采用 | **采用** | 需要额外判定逻辑 |
| 九种九牌 | 采用 / 不采用 | **采用** | 需要第一巡判定 |
| 食断（副露断幺九）| 允许 / 不允许 | **允许** | 影响断幺九的副露列 |
| 后付け（先副露后立直）| 不允许 | 不允许 | 立直必须门清 |

**建议做法**：把这张表变成一个配置结构体，默认值取上表，这样规则差异是数据而不是散布在
代码里的 `if`。测试时可以直接构造不同配置来验证。

```go
type Rules struct {
    KiriageMangan   bool // 切上满贯
    RenhouIsYakuman bool // 人和是否算役满
    AkaDora         int  // 赤宝牌数量，0 表示无
    Kuitan          bool // 食断
    // ...
}

func DefaultRules() Rules { /* 按上表返回 */ }
```
