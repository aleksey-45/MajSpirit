## 为什么这么分

```
docs/*.md       「这个项目是什么」  → 公开、稳定、别人要读
docs/local/     「我怎么做出来的」  → 私有、会变、只我自己读
```

**分开的直接好处：不用跑 `git status` 就知道哪份进仓库。**

## 引用约定

| 情况 | 写法 |
| --- | --- |
| 仓库文档 → 仓库文档 | 正常的 markdown 链接，`[规则集](规则集.md)` |
| 仓库文档 → `local/` 文档 | **纯文本路径**，如 `` docs/local/实现指南.md §2.1 ``。不用链接——读者拿不到那个文件 |
| `local/` 文档 → 仓库文档 | 正常的 markdown 链接，但路径要多一层 `../`，例如 `../规则集.md` |
| 任何文档 → 代码 | 相对路径链接，如 `[`internal/mahjong`](../../internal/mahjong/)` |
